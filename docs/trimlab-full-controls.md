# TrimLab Full Controls — セールコントロール統合シミュレータ

> **ステータス:** 企画書 / 実装優先度：低（開発末期に着手）
> **作成日:** 2026-05-21
> **前提:** TrimLab Phase 1（SheetAngle + MastBend の2パラメータ版）が完成していること

---

## 1. 目的 — なぜこの拡張をするか

Phase 1 の TrimLab は「シートを引くと帆がどう動くか」という**1変数の体験**にとどまっています。
しかし実際のセーリングでは、複数のコントロールが**互いに干渉しながら帆の形と位置を決定**します。

> 「バングを締めるとツイストが減る。そのためにトラベラーを下げてヒール力を逃がす。
> さらにカニンガムでドラフトを前進させて迎角のピークを安定させる。」

この一連の**相互依存する調整**を体感できるシミュレータが、中級〜上級セーラーの理論習得に必要です。

### 特に「ジブリーダー → リーチの開き」

ジブのフォアリード（ジブリーダー）は、シートの引く角度を変えることで：

- **前に出す** → リーチが開き（ツイスト増）、フットがタイト
- **後ろに引く** → リーチが閉まり（ツイスト減）、フットが緩む

この効果は「同じシート角でも、風が落ちたり強まったりしたときのパワー調整」に直結します。
現状の TrimLab にはこの概念が完全に欠落しています。

## 3. 実装するコントロール一覧

### 3.1 帆の形を変えるコントロール（セールシェイプ）

| コントロール | 操作範囲 | 帆への効果 | 物理パラメータへの反映 |
|---|---|---|---|
| **カニンガム** | 0.0〜1.0 | ラフ前縁のテンション → ドラフト最大点を前後に移動 | `draftPosition`: 0.35（緩）〜0.45（締）× コード長 |
| **アウトホール** | 0.0〜1.0 | フット下縁のテンション → ドラフト深さを変える | `draftDepth`: 12%（緩）〜8%（締）× コード長 |
| **バング（キッキングストラップ）** | 0.0〜1.0 | ブームを下に引く → リーチのツイストを抑制 | `twistRatio` を直接減少させる |
| **マストベンド** | 0.0〜1.0 | マスト前方への曲り → 帆全体のフラット化 | `flatness`: Cl スケールを低下、失速角を後退（N9-L5 で実装済み） |
| **バックステー** | 0.0〜1.0 | マストを後ろに引く → マストベンドを誘発、ジブのラフテンションも変化 | `mastBend` の補助パラメータとして合算 |

### 3.2 帆の位置を変えるコントロール（セールトリム）

| コントロール | 操作範囲 | 帆への効果 | 物理パラメータへの反映 |
|---|---|---|---|
| **メインシート** | 0〜30° | ブームの角度 → 迎角のベース | `sheetAngle`（Phase 1 で実装済み） |
| **トラベラー** | −100〜+100% | ブームの横位置 → ヒール力を変えずに迎角微調整 | `effectiveAlpha` に ±5° 程度を加算 |
| **ジブシート** | 0〜30° | ジブの迎角 | `jibSheetAngle`: メインとは独立した迎角 |
| **ジブリーダー（フォアリード）** | −100〜+100% | シートの引く角度 → リーチとフットのテンション比 | `leaderPosition`: リーチツイスト比とフットテンション比を分離 |

## 4. 物理モデルの拡張設計

### 4.1 現状（Phase 1）の入力

```typescript
interface PhysicsInput {
  sheetAngle: number;   // 帆の迎角
  mastBend: number;     // マストベンド（N9-L5）
  windSpeedKnots: number;
  windDirDeg: number;
}
```

### 4.2 拡張後（Full Controls）の入力

```typescript
interface SailShapeParams {
  cunningham: number;    // 0.0〜1.0  カニンガム
  outhaul: number;       // 0.0〜1.0  アウトホール
  vang: number;          // 0.0〜1.0  バング
  mastBend: number;      // 0.0〜1.0  マストベンド（バックステー含む）
}

interface TrimParams {
  sheetAngle: number;    // 0〜30°   メインシート
  traveler: number;      // -1.0〜1.0  トラベラー位置
  jibSheetAngle: number; // 0〜30°   ジブシート
  jibLeader: number;     // -1.0〜1.0  ジブリーダー位置
}

interface PhysicsInputV2 {
  shape: SailShapeParams;
  trim: TrimParams;
  windSpeedKnots: number;
  windDirDeg: number;
}
```

### 4.3 Cl(α) の変換パイプライン（2段構造）

```
SailShapeParams
    ↓ stage 1: 帆形状 → Cl/Cd 特性の変形
cunningham  → draftPosition → Cl ピーク角シフト
outhaul     → draftDepth   → Cl スケール（深いほど大きい）
vang        → twistRatio   → 高さ方向の Cl 分布
mastBend    → flatness     → Cl 全体のスケール＋失速角後退

    ↓ 出力: SailCharacteristics { Cl(α), Cd(α), stallAngle, twistProfile }

TrimParams
    ↓ stage 2: 帆位置 → 実効迎角の決定
sheetAngle  → baseAlpha
traveler    → effectiveAlpha = baseAlpha ± δ（ヒール力変化なし）
jibLeader   → jibTwistProfile（高さ方向の迎角分布）

    ↓ 出力: PhysicsResult（揚力・抗力・推進力・ヒール力）
```

### 4.4 ジブリーダーのモデル詳細

ジブリーダーの位置は「シートが帆に引く角度 θ_sheet」を決定します：

```
θ_sheet = atan2(leader_y, leader_x)  // リーダーの座標からシート角度を計算

リーチテンション = sin(θ_sheet) × シート張力
フットテンション = cos(θ_sheet) × シート張力

リーチテンション ↑ → ツイスト抑制（リーチが閉じる）
フットテンション ↑ → ドラフト深さ増加
```

高さ方向のツイスト分布は：

```typescript
// h: 0=下端, 1=上端
function jibTwistAtHeight(h: number, leaderPos: number): number {
  // リーダーを前に出すほど上端のツイストが増える
  const baseTwist = 5;          // 基準ツイスト [deg]
  const leaderEffect = leaderPos * 8;  // リーダー位置 × 感度
  return baseTwist + leaderEffect * h;
}
```

### 4.5 スロット効果（ジブ + メインの干渉）

2枚の帆がある場合、メインセールの揚力係数はジブとのスロット幅によって補正されます：

```typescript
// スロット効果による Cl 補正
// slotRatio: ジブリーチとメインラフの間隔 / ジブコード長
function slotEffect(slotRatio: number): number {
  // 最適スロット（0.1〜0.15）で最大15%の Cl 増加
  const optimal = 0.12;
  const boost = 0.15 * Math.exp(-((slotRatio - optimal) ** 2) / (2 * 0.03 ** 2));
  return 1 + boost;
}
```

## 6. 将来拡張：Python + XFOIL API

TypeScript の近似モデルで教育的には十分ですが、**本格的な圧力分布**が必要な場合：

```
フロントエンド（TS）         バックエンド（Python）
帆形状パラメータ送信   →   FastAPI サーバー
                              ↓
                         XFOIL を subprocess で呼び出し
                              ↓
                         翼断面の Cp 分布を計算
                              ↓
圧力カラーマップ受信   ←   JSON { cp: number[], x: number[] } を返す
```

**XFOIL の特徴：**
- Fortran 製、軽量・高速（1計算 < 1秒）
- NACA 翼型に加え任意の翼型座標を入力可能
- Re 数（レイノルズ数）ベースの実際の流体特性を計算

## 8. 新しく登場する概念

### 8.1 ドラフト位置（Draft Position）

帆の「最も膨らんでいる点」のコード長に対する位置（前縁から何%か）。
- **前進（40%前後）** → 低風速・クローズホールド向き。Cl ピークが低迎角側に来る
- **後退（50%前後）** → 高風速・ブロードリーチ向き。失速しにくくなる
- カニンガムを締める → ドラフトが前進する

### 8.2 ツイストプロファイル（Twist Profile）

帆の高さ方向に迎角が変化する分布。
- **マストトップ付近は風が弱い**（大気境界層の影響）ため、下より上を開けるのが基本
- バングを締める → ツイスト減少（上から下まで同じ角度）→ 高風速時に過負荷になりやすい
- ジブリーダーを前進 → ジブリーチのツイストが増加

### 8.3 スロット効果（Slot Effect）

ジブリーチとメインラフの間の隙間が「空気を加速させるノズル」として機能し、メインセールの Cl を増加させる現象。
スロットが狭すぎると逆効果（境界層の干渉）。最適幅はコード長の10〜15%。

- **リアルタイム CFD**（WebGPU でも教育用には過剰）

- **艇種ごとの固有パラメータ**（470専用セッティングなど）→ Phase 2 で検討
- **3D 風速グラデーション**（大気境界層の完全モデル）

## 11. 一言で言うと

> **「シートを引く」ではなく「帆を作る」体験を提供する。**
> セーリングにおいてトリムとは「既成の帆を動かすこと」ではなく「その場で理想の翼断面を作ること」である。
> この概念を体感できるシミュレータは、現時点で日本語で公開されているものは存在しない。
