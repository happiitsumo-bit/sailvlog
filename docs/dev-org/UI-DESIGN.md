## 0. デザイン原則

1. **トークンは流用する、捨てない。** `frontend/src/app/globals.css` の Claude-paper トークン（`--terra`/`--sage`/`--dijon`/`--font-display`/`--radius`系/`--shadow`系）をログイン・一覧・アップロードの3画面にそのまま使う。**リプレイ画面だけ例外**で、反省会＝暗い部屋のプロジェクタ投影が本番のため、海面Canvasとその直近コントロール一式は常時ダーク基調に固定する（サイトのライト/ダーク設定に連動させない。ADR-001のSPIKE screenshotが実測済みの基準）。ダーク面でも accent 色相（terra=赤系/sage=緑系/dijon=黄系）は保ち、彩度・明度だけ夜間表示用に上げてブランドの一貫性を保つ。
2. **デバッガ比喩は操作の設計指針であって、画面の語彙ではない。** 部員は非エンジニア。UI上の文言は日常語に翻訳する。

   | デバッガの概念 | UI操作 | 画面上の呼び方 |
   |---|---|---|
   | ステップ実行・speed | 再生/一時停止・1x/4x/8x | 「再生」「速さ」 |
   | ブレークポイント | レグ頭出し | 「レグ」チップ（スタート/上マーク/下マーク/フィニッシュ） |
   | ウォッチ式（変数比較） | 2艇ハイライト | 「比較する2艇」チェック |
   | コメント/issue | タイムライン注釈 | 「メモを残す」「反省メモ」 |
   | PRレビューへのリンク | 注釈込みURL共有 | 「この場面のURLをコピー」 |

3. **遠目・高コントラスト。** プロジェクタ投影を基準に、再生画面の主要数値（時刻・速度・艇ラベル）は最低16px相当・太字・高コントラストで組む。マウスホバー前提の微小UI（8px未満のハンドル等）を主要操作に置かない。
4. **スマホは事後の見返し（縦画面）が主用途。** 反省会中の操作はPC/プロジェクタ想定だが、着艇後や移動中にスマホで同じURLを開いても迷わないよう、再生画面は縦画面で「Canvas→コントロール→タイムライン→注釈」の1カラム積み上げに畳む。
5. **PRDにないものは描かない。** 自動解析数値（VMG・タック損失等）・ランキング・動画埋め込み・ライブ距離表示は本書のどの画面にも存在しない。2艇ハイライトは視覚的な強調のみで、派生指標は出さない。

## 1. ログイン画面（v1流用）

v1の認証画面をそのまま使う。新規デザイン投資はしない（本タスクのスコープ外）。

- **レイアウト**: `.form-page`（v1既存クラス）を継続使用。中央カード・タイトル・email/passwordフォーム・送信ボタン・register導線。
- **状態**: 空（初期表示）/ 送信中（ボタンdisabled+ラベル変化）/ エラー（`.form-error`帯でメッセージ表示）。
- **インタラクション**: 送信成功で一覧画面へ遷移。
- **モックアップは作らない**（既存v1画面を流用のため差分なし）。

## 2. セッション一覧（`/sessions`）

### レイアウト（デスクトップ）

```
┌─────────────────────────────────────────────────────────┐
│ navbar（v1流用）                                          │
├─────────────────────────────────────────────────────────┤
│ ページヘッダ: 「セッション」  [＋ アップロード] (btn-primary) │
│ フィルタバー: [すべて] [練習] [レース]        並び順: 新しい順▾ │
├─────────────────────────────────────────────────────────┤
│ ┌─ セッションカード ───────────────────────────────────┐ │
│ │ [練習|レース バッジ]           2026-07-20（月）        │ │
│ │ 江の島 定期practice                                    │ │
│ │ 風況メモ: 南西8-12kt、うねりあり（1行・省略記法）          │ │
│ │ 🚤6艇 · 💬注釈12件 · アップロード: マネ艇(佐藤)          │ │
│ └─────────────────────────────────────────────────────┘ │
│ （カード繰り返し）                                          │
└─────────────────────────────────────────────────────────┘
```

- カードは `.article-card` を流用したパターン（同じ角丸・ボーダー・hover浮き上がり）。バッジは `.boat-badge` 系トークンを練習=sage/レース=terraで塗り分け。
- カード全体がクリック領域＝`/sessions/[id]` へ。

### 状態
- **空**: `.empty-state` を流用。「まだセッションがありません」＋「最初のセッションをアップロード」CTA。
- **ロード中**: カード3枚分のスケルトン（背景`--card-warm`のシマー、角丸のみ・文字なし）。
- **エラー**: 一覧取得403/500時は `.form-error` 相当の帯をページ上部に表示し、再試行ボタン。
- **権限なし**（他Teamのセッション詳細への直接URLアクセス）: 一覧自体はTeamスコープでしか取得しないため一覧に出現しない。詳細への直リンクは`/sessions/[id]`側の403画面（3章参照）で扱う。

### インタラクション
- フィルタチップ（`.filter-chip`流用）でpractice/raceを絞り込み。
- カードクリックでリプレイへ。アップロード直後はアップロード画面からの遷移でこのリストを経由しない（FLOWS.md: 保存後は直接リプレイへ）。

### スマホ変形
- フィルタバーは横スクロール可能な1行チップ列のまま（`.navbar-row-bottom`と同じ横スクロールパターン）。
- カードは1カラム、風況メモは2行までのクランプ表示。

## 3. セッションアップロード（`/sessions/new`）

### レイアウト（デスクトップ）

```
┌─────────────────────────────────────────────────────────┐
│ ページヘッダ:「セッションを登録」                            │
├─────────────────────────────────────────────────────────┤
│ Step 1: 基本情報                                          │
│   [タイトル___________]  種別:(◉練習 ○レース)  日時:[____]  │
│   会場:[____________]  メモ:[__________________]         │
├─────────────────────────────────────────────────────────┤
│ Step 2: GPXファイル（複数選択可・艇ごとにラベル付け）          │
│  ┌───────────────────────────────────────────────┐     │
│  │  ここにGPXをドラッグ&ドロップ / [ファイルを選択]        │     │
│  └───────────────────────────────────────────────┘     │
│  取り込み済み:                                             │
│   ● 4423_track.gpx  → 艇名[4423 田中/佐藤_____] ✓ 解析OK  │
│   ● manebtt.gpx     → 艇名[マネ艇_____________] ✓ 解析OK  │
│   ✕ corrupt.gpx     → 解析エラー: GPX形式が不正です [削除]  │
├─────────────────────────────────────────────────────────┤
│ プレビュー: 全艇の航跡を薄いラインで重ね描き（Canvas・時刻同期確認用）│
├─────────────────────────────────────────────────────────┤
│                              [一覧に戻る]  [保存してリプレイを開く]│
└─────────────────────────────────────────────────────────┘
```

- Step1は`.form-group`をそのまま流用。Step2のドロップゾーンは`.empty-state`と同じ破線ボーダー意匠。
- 各行のファイル名はサーバ検証前でも即座に一覧化し、解析（DOMParser・フロント側／ARCH ADR-006）結果を行内バッジで即時反映する。

### 状態
- **空**（ファイル未選択）: ドロップゾーンのみ表示、保存ボタンはdisabled。
- **ロード中**（アップロード送信中）: 保存ボタンがスピナー付きdisabled、Step2はロック。
- **エラー**: 個別ファイルの解析エラーは行内に表示し全体送信をブロックしない（不正な1艇を除外して他艇は保存できる）。サーバ再検証（400/413）はページ上部の`.form-error`に表示。
- **権限なし**: 非TeamMemberはこのページ自体へのナビリンクが出ない（一覧・navbarから遷移しない）ため、直URLアクセス時のみ403画面（3画面共通の403）。

### インタラクション
- 艇名ラベルは自由入力（Track.boatLabelは自由記入・User非紐付け）。
- 「保存してリプレイを開く」がFLOWS.mdの主動線。「一覧に戻る」は複数セッションをまとめて登録する運用のための保持。

### スマホ変形
- Step1/Step2/プレビューを縦積み。ドラッグ&ドロップは非表示にし「ファイルを選択」ボタンのみ（タッチ環境でのDnD非対応を前提）。

## 4. リプレイ画面（`/sessions/[id]`）— 最重要画面

### 4.1 デザイン意図

反省会のプロジェクタ投影が主使用シーン。海面は常時ダーク（`--replay-bg: #0B1220` 系、globals.cssトークンの色相を流用しつつ独自のダークパレットを追加）。オーナーの「デバッガのように」を、非エンジニア語彙のまま次の4操作に翻訳する: **再生/速さ**・**レグ**・**比較する2艇**・**メモ**。

### 4.2 レイアウト（デスクトップ・プロジェクタ想定＝横長）

```
┌───────────────────────────────────────────────────────────────────┐
│ ← 一覧へ   江の島 定期練習 2026-07-20            [URLをコピー 🔗]   │
├───────────────────────────────────────┬─────────────────────────┤
│                                         │ 比較する2艇（最大2）        │
│                                         │ ☑ ● 4423 田中/佐藤        │
│                                         │ ☐ ● マネ艇                │
│         Canvas（航跡・テール・現在位置）    │ ☑ ● 1102 鈴木/高橋        │
│         ダーク海面・スケールバー付き        │ ☐ ● 0091 山本/井上        │
│                                         │ ☐ ● 2200 中村/木村        │
│                                         │ ☐ ● 3311 小林/加藤        │
│                                         ├─────────────────────────┤
│                                         │ 反省メモ（このセッション）    │
│                                         │ 00:14:02 なんでここでタック?│
│                                         │  — 主将                  │
│                                         │ 00:22:40 良い加速         │
│                                         │  — 田中                  │
│                                         │ [＋ 今の場面にメモを残す]   │
├───────────────────────────────────────┴─────────────────────────┤
│ [▶ 再生]  速さ [1x][4x][8x]        00:14:02 / 02:03:11            │
│ ─●━━━━━━━━━━━━◆━━━━━━━━━━━━◆━━━━━━━━━━━●─  （タイムライン+注釈ピン）│
│ [スタート] [上マーク L1] [下マーク L2] [フィニッシュ]  （レグチップ）    │
└───────────────────────────────────────────────────────────────────┘
```

- **左（可変幅・主役）**: Canvas。ダーク海面＋航跡ライン（艇ごとに固定配色: terra/sage/dijon＋3色追加でトーンだけ変えた6色パレット）＋各艇の現在位置ドット＋航跡テール（チェックで表示/非表示）＋スケールバー（例: 500m）。
- **右サイドバー（固定320px）**: 「比較する2艇」チェックリスト＋「反省メモ」パネル。ARCH ADR-001の通り艇の色はfront側でindex固定割当（DB非永続化）なので、チェックボックスの色スウォッチは一覧表示順そのまま。
- **下部フルワイド帯**: 再生コントロール（大きい・遠目対応）＋タイムラインスクラブバー（注釈はピン◆で可視化、クリックでその時刻へジャンプ）＋レグチップ行（クリックでそのレグ開始時刻へジャンプ＝ブレークポイントの比喩）。

### 4.3 主要コンポーネント

| コンポーネント | 役割 | 備考 |
|---|---|---|
| Canvasビューポート | 航跡・テール・現在位置描画 | ARCH: rAF+ref駆動、Reactステートの外。UIへの同期は≦10Hz |
| 艇リスト（比較チェック） | 2艇ハイライト選択 | チェック2件超は先勝ちで古い方を自動解除（UIポップオーバー等は出さない・シンプルに） |
| 反省メモパネル | 注釈の閲覧・追加 | 追加時は現在の再生時刻(tSec)を自動キャプチャ。艇/レグの紐付けは任意（プルダウン省略可） |
| 再生コントロール | 再生/一時停止・速度切替 | 1x/4x/8xの3段階のみ（ARCH範囲外の速度は作らない） |
| タイムラインスクラブバー | シーク・注釈ピン表示 | ドラッグ中はプレビューのみ、確定（pointerup）時に`history.replaceState`（ARCH: シーク確定時のみURL書き込み） |
| レグチップ | レグ頭出し | `Session.legs`から生成。手動補正はMVPのUI外（PATCH APIはあるが編集UIは別タスク） |
| URLコピー | 現在の再生状態を共有 | `?t=&boats=&leg=`。コピー後トースト表示 |

### 4.4 状態

- **ロード中**: Canvas領域はダーク背景のまま中央にスピナー＋「航跡を読み込み中…」。コントロール類はdisabled。
- **空**（Track 0件のセッション ＝ 通常発生しないが不整合データ時）: Canvas中央に「このセッションには航跡データがありません」＋一覧へ戻る導線。
- **エラー**（取得失敗）: Canvas領域に警告表示＋再読み込みボタン。反省メモパネルは非表示。
- **権限なし**（非TeamMember）: リプレイ画面全体をダーク基調のまま「このセッションを見る権限がありません」403表示に置換（ライトテーマの汎用エラーページに落とさず、共有URLを踏んだ非部員にも同じダーク画面で一貫させる）。
- **注釈0件**: メモパネルは「まだメモがありません。反省会での気づきを残しましょう」の空状態文言＋追加ボタンのみ。

### 4.5 インタラクション詳細

- 再生中はタイムラインの再生ヘッドが自動で進み、Canvas上の艇も同期して移動（テール表示ON時は直近区間の軌跡を残す）。
- レグチップをクリック → 一時停止した上でそのレグ開始時刻にジャンプ（反省会で「じゃあ上マークから見せて」に対応）。
- 注釈ピン（◆）をクリック → その時刻にシークし、右パネルの該当メモをハイライト・スクロール。
- 「今の場面にメモを残す」→ 入力欄がインライン展開（モーダルを開かない・議論のテンポを止めない）。
- 「URLをコピー」→ 現在のtSec・チェック中の艇ID・直近通過レグをクエリに埋め込みコピー、トースト「URLをコピーしました」。

### 4.6 スマホ変形（縦画面）

```
┌───────────────────────┐
│ ← 一覧へ      🔗 共有   │
│ 江の島 定期練習          │
├───────────────────────┤
│                       │
│   Canvas（正方形寄り）   │
│                       │
├───────────────────────┤
│ [▶] [1x|4x|8x]  14:02/2:03:11 │
│ ─●━━◆━━◆━━━●─        │
│ [スタート][L1][L2][Fin]（横スクロール）│
├───────────────────────┤
│ ▾ 比較する2艇（折りたたみ） │
├───────────────────────┤
│ ▾ 反省メモ（折りたたみ・   │
│    タップで下からシート展開）│
└───────────────────────┘
```

- 右サイドバーの2パネルは縦積みの折りたたみアコーディオンに変形（初期は閉）。着艇後の見返しでは「まず再生」が最優先のため、メモ/比較はデフォルト非表示で画面を圧迫しない。
- レグチップ行は横スクロール（navbar-row-bottomと同じ挙動）。
- タッチでのシークはタイムラインバーの直接ドラッグに加えて、Canvas上の左右スワイプでも±5秒シークできるようにする（プロジェクタ操作と違い、片手操作前提）。
