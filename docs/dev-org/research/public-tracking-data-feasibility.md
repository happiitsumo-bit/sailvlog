### RQ-A の所見（推奨まで。決定ではない — 決定は architect）

- 独立ソースの一致状況: **分かれている（サービスごとに扱いが異なる）**。SAP=API存在するが特別権限必須（第三者への一般提供ではない）／TracTrac=主催者承認+管理者への依頼が必須（公開の恒常エンドポイントではない）／Metasail・YB Tracking・RaceQs=エクスポート機能の有無を公式ページから確定できず「不明」／Kattackは二次情報のみで確証なし。打ち切り理由: 各サービス1〜2ソースで「イベント依存」または「不明」という結論が繰り返し出たため（上限5件到達、一部は独立2ソース一致）
- 反証探索の結果: 「公開データが取れる」ことを支持する反証（＝広く一般公開されているサービスの実例）を探したが、本調査では見つからなかった（検索語: `"tractrac.com" event replay public 2026 KML download`、`YB Tracking races GPX export terms of use API`）。RaceQsの過去大会ページが「見られる」実例として現存する点のみが、部分的な反証（閲覧レベルでは公開されている）

### RQ-B の所見（推奨まで。決定ではない — 決定は architect）

- 独立ソースの一致状況: **確証なし・情報不足**。今回確認できた一次ToS（YB Tracking）には、データ再利用に関する明示規定が見当たらなかった＝「規約上OK」ではなく「規約が沈黙している」だけであり、これを許可と解釈するのは誤り。TracTrac・SAP・Metasail・RaceQsについては、ToS本文そのものへの到達（検索・直接URL）ができず「不明」のまま。**「取れる」と「使ってよい」を区別する本RQの核心部分は、5件の調査上限に達しても十分な一次情報が得られなかった**
- 反証探索の結果: 「再配布・スクレイピングが明確に禁止されている」という反証を探した結果、MarineTraffic（Kpler）については検索結果の要約レベルで「スクレイピング禁止」の記述が見つかった（一次原文は403で直接確認できず、確度は中）。TracTrac/SAP/Metasail/RaceQsについては、禁止条文の有無どちらの反証も見つけられなかった（検索語: `TracTrac terms of use data export KML API`、`sapsailing.com terms of use legal notice data reuse`）
- 打ち切り理由: 上限5件到達（うち2件はrobots.txt/ToSページへの技術的到達失敗という「調査した上での不明」）

### RQ-D の所見（推奨まで。決定ではない — 決定は architect）

- 独立ソースの一致状況: **一致（用途不適合という結論で2ソース一致）**。OpenSeaMapは水深データが主でレース航跡ではない。AISは大型船向けの仕組みで小型セーリング艇には通常搭載されないため、代替ソースとしては両方とも**sailvlogの用途（大学ヨット部のレース航跡）には構造的に不適合**という点で一致。ライセンス自体（ODbL/CC BY-SA、AISは商用ライセンス）は公式情報で確認済み
- 反証探索の結果: 「AISで小型セーリング艇も追跡できる」事例（クラス400/AISビーコン装着レース艇など）がないか探したが、本調査の時間箱内では発見できなかった（検索語: `MarineTraffic AIS data terms of use scraping API license`）。長距離オーシャンレース（Fastnet, Sydney Hobart等）では安全規則でAIS搭載を義務付ける場合があり、その文脈でのAISトラッキングは実在しうる点は留保（本調査の対象＝大学インカレ規模とは前提が異なる可能性がある）
