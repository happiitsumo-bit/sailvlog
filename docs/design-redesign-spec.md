# デザイン再設計 仕様書

## 1. 目的

現在の「汎用ブログ風ブルー系デザイン」から、**セーリング競技に特化したブランド感のあるデザイン**へ刷新する。
ヨット雑誌の表紙のような「本物感・クール・海らしさ」を前面に出し、ユーザーが開いた瞬間に「セーリング専用プラットフォームだ」と感じられるようにする。

---

## 2. 完成イメージ

### カラーパレット（変更前 → 変更後）

| トークン | 変更前 | 変更後 | 意味 |
|---|---|---|---|
| `--bg` | `#f0f2f5`（グレー） | `#f0f9ff`（薄い水色） | 海の水面感 |
| `--accent` | `#3ea8ff`（スカイブルー） | `#06b6d4`（シアン） | 波しぶき・爽快感 |
| `--accent-dark` | `#0f83fd` | `#0891b2` | |
| `--accent-light` | `#e8f4ff` | `#e0f7fa` | |
| `--primary`（新規） | なし | `#0a2342`（ディープネイビー） | 深い海・本格感 |
| `--text` | `#0f172a` | `#0a2342`（primary と統一） | |
| `--border` | `#e2e8f0` | `#bae6fd`（薄いシアン寄り） | 海面を連想 |

### フォント
- 見出し系: 現行ヒラギノ系を維持しつつ、`letter-spacing` / `font-weight` をより引き締める
- ナビバーブランドロゴ: ⛵ → ヨットアイコン的なSVGに変更 or テキストデザイン強化

### 全体の雰囲気
```
[before] 白背景 + 水色アクセント → 普通の技術ブログ風
[after]  薄い水色背景 + ネイビー × シアン → ヨット雑誌・マリン専門誌風
```

## 3. 実装する変更一覧

### A. デザイントークン全体刷新（globals.css）
- カラー変数をネイビー × シアン × 薄水色系に変更
- `--primary` 変数を新設（ネイビー用）
- ボートバッジ・タグ・ボタンの配色を新パレットで統一

### B. ナビバー（Navbar.tsx + globals.css）
- 背景色: `rgba(255,255,255,0.92)` → `rgba(10, 35, 66, 0.95)`（ネイビー半透明）
- テキスト色: ダーク → ホワイト系
- ブランドロゴ `sailvlog` のスタイル強化（シアンアクセントカラー）
- ナビリンクホバー: シアン下線アニメーション
- 「記事を書く」ボタン: シアン系 primary カラーに

### C. トップページ（page.tsx + globals.css）
- **ヒーローバナー追加**: 最新記事一覧の上に、セーリングをイメージした波線SVGバナーを表示

  - 背景: ネイビー → シアンのグラデーション + 波形SVGアニメーション
- サイドバーの艇種リンクに⛵アイコンを付ける（現行も `::before` で付いているがスタイル強化）

### D. 記事カード（ArticleCard.tsx + globals.css）
- カード左端に **ネイビーのアクセントライン**（`border-left: 3px solid var(--primary)`）を追加

- ホバーアニメーション: 現行 `translateY(-2px)` はそのまま、border カラーをシアンに

## 5. 新しく登場する概念・技術

### SVG インライン波形（Wave SVG）
- CSS/HTML の `<svg>` タグをそのままコードに埋め込む手法
- 外部画像ファイル不要。背景の波形装飾に使う
- `path` の `d` 属性で波の形を数値で定義する
- React では `<svg>` をそのまま JSX に書ける

### CSS グラデーション（linear-gradient）
- `background: linear-gradient(135deg, #0a2342, #06b6d4)` のように方向と色を指定
- 現行コードでもボートバッジ等で使用済み。今回はヒーロー背景に本格活用
