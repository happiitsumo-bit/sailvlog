# sailvlog UI Kit

Interactive recreation of the sailvlog v2 product surface — Hero, Feed, Q&A, Learn, Sailors. Lifted directly from `sailvlog/frontend/src/**`.

Open `index.html` for the click-through prototype. Components are React JSX components loaded via Babel-standalone.

## Components

- `Navbar.jsx` — sticky top + class-flag bottom row
- `Hero.jsx` — WIND READS YOU display with stats bar
- `ArticleCard.jsx` — article preview, vertical flare bar on hover
- `QuestionCard.jsx` — Q&A row with metrics + solved pill
- `PostCard.jsx` — timeline post
- `CourseCard.jsx` — Learn module with diagonal skew background
- `SailorCard.jsx` — profile card
- `Composer.jsx` — 300-char feed input
- `Sidebar.jsx` — module-style right rail
- `ClassFlag.jsx` — six inline SVG class flags
