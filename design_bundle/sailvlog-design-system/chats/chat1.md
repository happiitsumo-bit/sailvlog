Claude のペーパーUI 風に全面刷新しました：

**変更点**
- **配色** — 深海ティール → 暖かいクリーム紙 (`#F4F0E8` 基調)、テラコッタ + セージ + ディジョンのアクセント
- **タイポ** — Space Grotesk → **Source Serif 4** (display) + Inter (body)
- **角丸** — 2–4px のレーシング系 → 10–20px の柔らかいラジオ
- **影** — グロウ多用 → 低コントラストのソフトシャドウ
- **コピー** — 全大文字・モノスペース → センテンスケース・エディトリアル調

トークン (`colors_and_type.css`) と UI Kit (`ui_kits/sailvlog/kit.css` + `Shell.jsx`)、Design System タブの主要カード（surface / accent / fg / type-display / type-scale / buttons / elevation）を再生成済みです。

**残る注意点**
- 一部のセカンダリプレビューカード（article-card / question-card / post-card / form-controls / logo など）は色のみ自動置換で、レイアウトはレーシング期のままです。気になるカードがあれば「これを刷新して」と指定してください個別に作り直します。
- フォントは Google Fonts の Source Serif 4 を使用。Claude の本物の Copernicus 書体は配布されていないため近似です。

**お願い** — UI Kit (`ui_kits/sailvlog/index.html`) を開いて、Hero / カード / ナビの雰囲気を確認してください。Claude UI に寄せ過ぎ / 寄せ足りない、どこを詰めたいか教えていただければ調整します。
